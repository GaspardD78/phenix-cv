## À quoi sert l'export

Une fois votre CV prêt, vous l'enregistrez sur votre ordinateur : en **PDF** pour l'envoyer tel quel, ou en **Word** (.docx) si l'employeur demande un document modifiable.

## Comment faire

1. Dans l'éditeur de CV, vérifiez que votre CV a la longueur prévue. Un message vous prévient s'il dépasse une page : le PDF le répartit alors sur plusieurs pages, sans rien couper. Au-dessus de l'aperçu, choisissez **Pages du PDF** pour voir le fichier exactement tel qu'il sera exporté, page par page (sauts de page, marges, numéros).
2. Cliquez sur **Exporter PDF** ou **Exporter DOCX**.
3. Choisissez le dossier et le nom du fichier.

Pour le PDF, l'application utilise le moteur de Windows (WebView2), puis Microsoft Edge ou Google Chrome si besoin. Si aucun ne fonctionne, elle ouvre l'impression de Windows : choisissez « Enregistrer au format PDF ».

## Ce qu'un recruteur cherche

Un fichier qui s'ouvre sans problème, dont la mise en page ne bouge pas, et dont le texte peut être sélectionné. Le PDF garde votre mise en page ; le Word permet des retouches.

## Exemples

- **Bonne pratique** : un PDF nommé « Camille-Martin-CV.pdf », et relu une fois ouvert.
- **Mauvaise pratique** : un fichier « document final (2).pdf » qui se perd dans les téléchargements.

## Erreurs à éviter

- Envoyer un CV de deux pages sans l'avoir voulu : relisez le PDF avant de l'envoyer.
- Oublier la version Word si une candidature en demande une.
- Modifier le PDF ailleurs : il ne se met plus à jour avec votre profil.
